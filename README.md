# FoldbyHuse

16 moderne rækkehuse på Gammelager i Foldby, Danmark.

## 📁 Projektstruktur

```
/workspace
├── index.html              # Hovedversion (seneste)
├── index-v1-classic.html   # V1: Originalt design
├── index-v2-minimal.html   # V2: Minimalistisk design  
├── index-v3-brutalist.html # V3: Brutalistisk design
├── css/
│   ├── styles.css              # Hoved CSS
│   ├── styles-v1-classic.css   # V1 CSS
│   ├── styles-v2-minimal.css   # V2 CSS
│   └── styles-v3-brutalist.css # V3 CSS
├── js/
│   ├── main.js              # Hoved JavaScript
│   ├── main-v1-classic.js   # V1 JS
│   ├── main-v2-minimal.js   # V2 JS
│   └── main-v3-brutalist.js # V3 JS
├── images/                  # Billeder
└── archive/                 # Arkiverede gamle versioner
```

## 🎨 Design Versioner

### V1 Classic (Original)
- Traditionelt dansk boligdesign
- Varme farver med rød accent (#C44538)
- Detaljeret hero-sektion med stats
- Fuld funktionalitet

### V2 Minimal
- Rent, minimalistisk udtryk
- Blågrå accent (#2c3e50)
- Enkel typografi
- Fokus på indholdet

### V3 Brutalist
- Råt, kantet design
- Monospace skrifttype
- Grayscale billeder med hover-effekt
- Store overskrifter med outline-effekt
- Høj kontrast

## ⚡ Features

- ✅ Responsivt design (mobile-first)
- ✅ Modal-visning af boliger
- ✅ Fotogalleri med navigation
- ✅ Kontaktformular med validering
- ✅ Accessibility (ARIA labels, focus traps)
- ✅ SEO optimeret (meta tags, structured data)
- ✅ Lazy loading af billeder
- ✅ Mobile hamburger menu

## 🚀 Brug

Åbn `index.html` i en browser for at se hovedversionen, eller prøv de alternative designs:

- `index-v1-classic.html` - Originalt design
- `index-v2-minimal.html` - Minimalistisk
- `index-v3-brutalist.html` - Brutalistisk

## 🛠️ Teknologi

- HTML5
- CSS3 (Custom Properties)
- Vanilla JavaScript (ES6+)
